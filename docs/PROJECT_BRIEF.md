# One Piece Watch Companion — Project Brief

## 1. Project idea
A personal website for a friend that encourages him to watch One Piece and makes the watching experience more fun, personal, and interactive.

## 2. Main user
The main user is one friend who is watching One Piece.

## 3. Main goal
Help the friend track progress, see episode or arc references, receive personal thank-you messages, and send reactions after important moments.

## 4. MVP features
The first version should include:

- A home page with a personal welcome message
- A progress tracker for watched episodes or arcs
- Reference cards connected to episodes, arcs, or important moments
- Thank-you/reward messages after progress milestones
- A simple feedback or email flow for reactions
- A simple manual content-management approach for the site owner

## 5. Not included in MVP
The first version should not include:

- User accounts
- Complex authentication
- Public social features
- Payment features
- A large admin dashboard
- A mobile app
- Complex database design before the content model is clear

## 6. Planned technical direction

- Frontend: Next.js
- Backend: Next.js API routes or server actions
- Database: to decide after the content model is clear
- Deployment: Vercel
- Project management: GitHub Issues, GitHub Projects, labels, milestones, and pull requests

## 7. Repository and deployment rule
The deployable Next.js application should stay at the repository root so Vercel deployment stays simple.

## 8. Success definition
The MVP is successful when the friend can open the website, understand their current One Piece progress, see personalized references, and send a reaction or message after important moments.
